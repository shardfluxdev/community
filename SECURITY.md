# Reporting a security vulnerability

Use [GitHub private vulnerability reporting](https://github.com/shardfluxdev/community/security/advisories/new), or email [shardflux@heliosone.fi](mailto:shardflux@heliosone.fi?subject=Shardflux%20security%20report) with the subject **Shardflux security report**.

This channel covers Shardflux client packages, the API, and cloud workspaces. You can report through this repository even when the affected code lives elsewhere.

Include the affected package and version or service, the potential impact, and the smallest reproduction you can safely share. Do not put vulnerabilities, credentials, customer data, or exploit details in public issues.

The Shardflux team will investigate and coordinate any fix and disclosure with the reporter. If you accidentally exposed a credential, revoke it and report the exposure privately; do not paste the credential into the report.
